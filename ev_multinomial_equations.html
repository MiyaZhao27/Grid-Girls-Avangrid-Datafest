Multinomial Logistic Regression Specification: 3-Class EV Classification
Equation Component Mathematical Formulation
1. Log-Odds Equations (Reference = No EV)
Log-Odds: Level 1 EV vs. None $$\eta_{i, \text{Lvl1}} = \ln \left( \frac{P(\text{EV}_i = \text{Lvl1})}{P(\text{EV}_i = \text{None})} \right) = \beta_{0,\text{Lvl1}} + \sum_{h=2}^{24} \beta_{h,\text{Lvl1}} \text{kWh}_{ih} + \gamma_{1,\text{Lvl1}} \text{Peak}_i + \gamma_{2,\text{Lvl1}} \text{HighUse}_i + \mathbf{Z}_i^\top \boldsymbol{\delta}_{\text{Lvl1}}$$
Log-Odds: Level 2 EV vs. None $$\eta_{i, \text{Lvl2}} = \ln \left( \frac{P(\text{EV}_i = \text{Lvl2})}{P(\text{EV}_i = \text{None})} \right) = \beta_{0,\text{Lvl2}} + \sum_{h=2}^{24} \beta_{h,\text{Lvl2}} \text{kWh}_{ih} + \gamma_{1,\text{Lvl2}} \text{Peak}_i + \gamma_{2,\text{Lvl2}} \text{HighUse}_i + \mathbf{Z}_i^\top \boldsymbol{\delta}_{\text{Lvl2}}$$
2. Class Probability Equations (Softmax)
Probability: No EV (Baseline) $$P(\text{EV}_i = \text{None}) = \frac{1}{1 + \exp(\eta_{i,\text{Lvl1}}) + \exp(\eta_{i,\text{Lvl2}})}$$
Probability: Level 1 EV $$P(\text{EV}_i = \text{Lvl1}) = \frac{\exp(\eta_{i,\text{Lvl1}})}{1 + \exp(\eta_{i,\text{Lvl1}}) + \exp(\eta_{i,\text{Lvl2}})}$$
Probability: Level 2 EV $$P(\text{EV}_i = \text{Lvl2}) = \frac{\exp(\eta_{i,\text{Lvl2}})}{1 + \exp(\eta_{i,\text{Lvl1}}) + \exp(\eta_{i,\text{Lvl2}})}$$
